## v0.1.0 (Nov 3, 2026)

* **Sarvam AI Sovereign Agent & MCP:** Added official `sarvam-agent` reference implementation and native `mcp:sarvam` tool protocol support for frontier Indic models (`sarvam/sarvam-105b` and `sarvam/sarvam-2b`).
* **Neon Function Triggers:** Native integration with Neon Postgres for scale-to-zero scheduled cron tasks.
* **Generic BYOAI Provider Execution:** Provider-agnostic on-the-fly execution supporting arbitrary inference providers (`SARVAM_API_KEY`, etc.) with zero vendor markup.
* **Brand Standardization:** Unified naming as OpenLiate across cloud deployment, OAuth 2.1 metadata, health endpoints, and CLI binaries (`@openliate/liate`).
* **Community Sponsorship:** Added `.github/FUNDING.yml` to support open-source development through GitHub Sponsors.

## v0.0.9 (Nov 2, 2026)

* **Developer Documentation Suite (`docs.openliate.tech`):** 20 comprehensive documentation guides covering introduction, doctrine, quickstart, and API references.

## v0.0.8 (Nov 2, 2026)

* **Multi-Cloud Link Mesh:** Implemented `liate link`, `relink`, and `unlink` with automated OAuth 2.1 PKCE for Neon, Supabase, and Vercel (2.5M Free Runs).
* **RFC 9562 UUIDv7 Standard:** Implemented time-ordered monotonic identifiers across all Liate API sessions and execution traces.
* **Local Docker Stack:** Added multi-stage Alpine Docker runtime and `docker-compose.yml`.
* **46 Passing Tests:** Complete unit test verification across all 5 architectural layers (196 assertions).

## v0.0.7 (Oct 31, 2026)

* **Liate API Pure Engine Server:** High-performance Hono-based execution server with `GET /health`, `GET /agents`, and `POST /run`.
* **Sovereign Identity Verification:** Added `verify_identity` tool with 12-digit Aadhaar Verhoeff checksum algorithm and 10-character PAN card format validation.
* **Environment Resolvers:** Added safe `$VAR` expansion and automatic secret masking in Layer 5 (`[E]`).

## Overview

The **Agent Protocol Interface (Liate API)** server is a high-performance HTTP engine powered by [Hono](https://hono.dev). It exposes autonomous agent classes as production-ready microservices with CORS enabled out-of-the-box.

---

## Starting the Server

```bash
openliate serve --port 8080
```

```
===========================================================
  OPENLIATE HTTP SERVER — HIGH PERFORMANCE AGENT ENGINE
  Listening on: http://localhost:8080
===========================================================
```

---

## Key Features

* **CORS by Default:** Frontend applications (Next.js, React, React Native) can invoke agents directly.
* **Dynamic API Key Injection:** Pass API keys on the fly via headers (`x-sarvam-api-key`) or request body (`keys.SARVAM_API_KEY`).
* **Monotonic Session Retention:** Automatic RFC 9562 UUIDv7 session generation across multi-turn runs.
* **On-the-Fly ReAct Execution:** Runs the autonomous loop and returns step-by-step reasoning traces and tool outputs.

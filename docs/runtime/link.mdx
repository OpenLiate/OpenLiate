## Overview

`liate link` (`src/link/`) establishes a secure, zero-configuration cloud mesh between your local runtime and top-tier cloud providers using **OAuth 2.1 with PKCE (RFC 7636)** and **Dynamic Client Registration (RFC 7591)**.

---

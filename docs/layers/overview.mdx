## The LIATE Specification

OpenLiate decomposes agent design into five isolated, modular layers. In `agent.json`, each layer corresponds to a top-level key:

```json agent.json
{
  "L": "sarvam/sarvam-105b",
  "I": { "memory": "sessions/agent-data" },
  "A": { "name": "analyst", "maxSteps": 10 },
  "T": [ "mcp:fetch", "verify_identity" ],
  "E": { "SARVAM_API_KEY": "$SARVAM_API_KEY" }
}
```

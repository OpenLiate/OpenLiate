## <a id="instant-install"></a>[0] Instant Install (Zero Dependencies)

```bash
# 1-Click Run via npx (Zero local install):
npx openliate run agent.json "Hello World"

# Or Install Globally:
npm install -g openliate

# Windows (PowerShell):
powershell -c "irm https://openliate.tech/install.ps1 | iex"

# macOS / Linux (cURL):
curl -fsSL https://openliate.tech/install.sh | sh
```

> **Prefer 1-Click in Browser?**  
> Run OpenLiate instantly inside [GitHub Codespaces](https://codespaces.new/openliate/openliate) with zero local setup.


> **Why 5 Lines? The AI Agent Architecture:**  
> On stage, NVIDIA CEO Jensen Huang proved that an AI Agent is fundamentally 5 elements: **Model (`L`)**, **Knowledge (`I`)**, **Harness (`A`)**, **Tools (`T`)**, and **Sandbox (`E`)**. LIATE maps this directly into 5 lines of declarative execution.

```jsonc
{
  "L": "sarvam/sarvam-105b",                                                          // [L] LLM / Model: Text, Reasoning (Sarvam 105B), Decisions, Multimodal
  "I": { "memory": "sessions/hello-agent" },                                          // [I] Integration / Knowledge: Session Memory, State, Neon Postgres, Frameworks
  "A": { "name": "hello_agent", "intent": "Autonomous Agent", "skills": ["vercel/nextjs"] }, // [A] Agent / Harness: Name, Intent, Vercel skills.sh (1.5M+ skills), ReAct Loop
  "T": ["fetch"],                                                                     // [T] Tools: MCP v2 (Local Stdio & Remote SSE), Custom APIs
  "E": { "SARVAM_API_KEY": "$SARVAM_API_KEY" }                                        // [E] Environment / Sandbox: Secrets, Cloud Execution, Guardrails
}
```

```bash
# Execute your agent (reads L·I·A·T·E directly from agent.json)
liate run agent.json "Hello Agent World!"
```

> **Prefer writing code directly?**  
> Direct language packages for **npm**, **PyPI**, and other OOP class-based languages (TypeScript, Python, Java, C#, etc.) are coming soon.  
> On Day 1 (`v0.1.0`), Liate is 100% focused on the zero-dependency **Autonomous Runtime Engine (`agent.json`)**.

## <a id="runtime-engine"></a>[1] Core Engine: OM (Orchestration Module)

**Liate's Orchestration Module (OM) is the autonomous runtime engine** — just like Docker executes containers and Ollama executes models, **Liate executes AI agents via OM** across the 5 orthogonal layers (`L · I · A · T · E`).

Liate provides three sovereign deployment targets across local hardware, regional cloud, and worldwide edge:

---

### #1 Run Locally (Native CLI & 1-Click Docker Engine)

Run agents anywhere on your own hardware with full Dual-MCP superpowers:

```bash
# 1. Native Standalone CLI
liate run agent.json "Hello Agent World!"

# 2. Local AI Gateway & Engine Server (ekaRoute 1.62B+ Free Token Gateway · OpenAI Compatible)
openliate serve --port 3000

# Connect Cursor, Claude Code, Cline, Copilot, or Python SDK to your local port:
export OPENAI_BASE_URL="http://localhost:3000/v1"
export OPENAI_API_KEY="any-key"

# 3. Production Docker Engine (Node 24 + Python 3.14 + Astral uv + npx)
docker compose up -d
```

* **Full Dual-MCP Support:** Execute both local Stdio MCP tools (`npx`, `uvx`) and remote HTTP/SSE MCP endpoints.
* **100% Offline & Private:** Zero cloud dependencies, zero external network hops, zero telemetry.
* **Your Keys:** Reads `$SARVAM_API_KEY` (or OpenAI/Claude) directly from your local `.env`.
* **Universal Deployment:** Run on your laptop, Mac/Linux/Windows, any VPS (DigitalOcean, Hetzner, AWS), or private Kubernetes cluster.

### #2 Run in Regional Cloud (Co-Located Postgres Memory · 2.5M Free Runs/mo)

Link your Vercel, Neon, and Supabase accounts with Liate in one click to deploy your autonomous agent engine across all three for `< 1ms` database retrieval:

```bash
# 1-Click Link & Auto-Deploy across all 3 platforms (2.5M Free Runs/mo for $0.00)
liate link

# Or link individual clouds:
liate link --neon             # Provisions project 'liate' & deploys engine (2 vCPU, 8GB RAM + pgvector)
liate link --vercel           # Deploys serverless HTTP engine (1M runs, auto-scales to 0)
liate link --vercel-daemons   # Deploys 24/7 containerized background daemon worker (Node 24 + Python + uvx)
liate link --supabase         # Deploys Edge Function (500k runs + pgvector store)

# Relink / refresh tokens and redeploy anytime:
liate relink                  # Relink all clouds with fresh OAuth
liate relink --supabase       # Relink specific provider

# Unlink & clear saved credentials:
liate unlink --all            # Safely clear all tokens from disk and .env.local

# Optional: set private model keys
liate env set SARVAM_API_KEY="your-key-here"
```

* **Neon Functions (1,000,000 / mo):** Linux Node.js (**2 vCPU, 8 GB RAM**) co-located directly with serverless Postgres + `pgvector` and automated Neon Cron triggers.
* **Vercel Functions & Daemons (1,000,000 / mo):** Fluid Compute functions for Next.js apps, plus 24/7 background agent runners via October 15, 2026 **Vercel Daemons** (`Dockerfile`).
* **Supabase Edge (500,000 / mo):** Deno V8 edge functions co-located with Postgres auth and realtime database webhooks.
* **Zero Cross-Region Latency:** Compute lives in the same data center as your database—eliminating network bottlenecks.

## <a id="aum-architecture"></a>[3] Architecture: The 5 Layers (AUM)

Every agent implements the **Agent Unified Manifest (AUM)** across 5 decoupled pillars declared as class properties or manifest keys:

| Layer | Name | Core (Built-in) | Community PRs |
|---|---|---|---|
| **L** | **Large Models** | Sarvam AI (`hub/llm/sarvam.json`) <sup>IN</sup> | Add Claude, Nano Banana, SeaDance, OpenJev... |
| **I** | **Integration** | Libraries (Zod), in-memory state, persistent memory | Add Neon Postgres, LlamaIndex, Redis, webhooks, repos... |
| **A** | **Agent** | Name, intent, ReAct loop, Vercel `skills.sh` inject | Add subagents, multi-agent swarms, wrap CrewAI/LangGraph... |
| **T** | **Tools** | MCP v2 (Local stdio & Remote SSE) | Add filesystem, GitHub, remote MCP servers... |
| **E** | **Environment** | Pure `.env` key reader & edge sandbox | Add edge isolate configs... |

> **Unifying the Two Greatest Standards:** Liate natively unifies **Vercel Labs' `skills.sh`** (1.5M+ portable domain skills injected into Layer **[A]**) and **Anthropic's Model Context Protocol (MCP)** (modular tools and actuators in Layer **[T]**). Zero custom glue code required.
